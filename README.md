# Tick-Tock Time Heroes ⏰

A 20-round clock game for Grade 3 (Cambridge Primary Mathematics, Stage 4, Unit 2: Time).

- **MOVE IT!** rounds: students drag the short (hours) and long (minutes) hands to match the written time.
- **SAY IT!** rounds: the class reads the clock aloud before the timer ends.
- Every round has a timer (10, 15 or 20 seconds), then the correct answer is revealed.
- Correct answers before the timer ends earn a star and a celebration.

Teacher keys: **Space** = class got it 🎉 · **Enter** = next round · **F** = full screen
